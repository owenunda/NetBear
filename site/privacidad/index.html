Política de privacidad

Vigente desde el 26 de noviembre de 2026

NetBear no recopila, guarda ni comparte datos personales. Todo lo que la app lee se procesa en tu equipo, en memoria, y nunca sale de él.

Quién es el responsable

NetBear es una aplicación gratuita y de código abierto para Windows, desarrollada por owenunda. Si tienes preguntas sobre esta política, escribe a owenunda@gmail.com.

Qué información lee la app

Para animar al oso, NetBear lee de Windows, cada segundo:

  • Contadores de tráfico de red. La cantidad total de bytes enviados y recibidos por tus adaptadores de red, y si cada adaptador tiene puerta de enlace. Con esto calcula la velocidad que muestra el oso y el texto ↓ descarga ↑ subida.
  • El tema de la barra de tareas. Si está en modo claro u oscuro, para elegir los colores del oso.

NetBear no lee el contenido de tu tráfico, ni las páginas que visitas, ni tus direcciones IP, nombres de red, archivos o datos de tu cuenta. Los valores que lee solo se usan en memoria para dibujar el ícono y se descartan en la siguiente medición. No se guardan en disco.

Qué guarda en tu equipo

Solo una cosa, y solo si activas Iniciar con Windows (en el menú de la app o en el instalador): un valor llamado NetBear en HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run con la ruta del programa. Se borra cuando desactivas la opción o desinstalas NetBear.

La versión de Microsoft Store no escribe nada en el registro: el inicio con Windows lo controla Windows, en Configuración › Aplicaciones › Inicio.

Conexiones a internet

NetBear no se conecta a ningún servidor. No tiene telemetría, analíticas, publicidad, informes de errores ni actualizaciones automáticas. Lo que hace no depende de ningún servicio externo.

La opción GitHub del menú abre la página del proyecto en tu navegador. A partir de ahí aplica la declaración de privacidad de GitHub.

Datos compartidos con terceros

Ninguno. NetBear no vende, alquila ni comparte información con nadie, porque no la recopila.

Microsoft Store

Si instalas NetBear desde Microsoft Store, Microsoft procesa los datos de la descarga y la instalación según la declaración de privacidad de Microsoft. El desarrollador solo recibe informes agregados de la Store, como el número de descargas, que no identifican a ninguna persona.

Este sitio web

Este sitio está alojado en GitHub Pages. No usa cookies, analíticas ni fuentes o scripts de terceros. GitHub puede registrar datos técnicos de las visitas, como la dirección IP, para operar y proteger el servicio, según su propia declaración de privacidad.

Menores de edad

NetBear no recopila datos de nadie, incluidos menores de 13 años.

Tus derechos

Como NetBear no guarda datos personales, no hay información tuya que consultar, corregir o borrar. Si aun así tienes una solicitud o una duda, escríbenos y te responderemos.

Cambios a esta política

Si NetBear cambia la forma en que maneja la información, esta página se actualizará antes de publicar esa versión y la fecha de arriba cambiará. El historial completo está en el repositorio del proyecto.
