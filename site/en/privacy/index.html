Privacy policy

Effective November 26, 2026

NetBear does not collect, store or share personal data. Everything the app reads is processed on your device, in memory, and never leaves it.

Who is responsible

NetBear is a free, open-source app for Windows developed by owenunda. If you have questions about this policy, write to owenunda@gmail.com.

What the app reads

To animate the bear, NetBear reads the following from Windows once per second:

  • Network traffic counters. The total number of bytes sent and received by your network adapters, and whether each adapter has a default gateway. It uses these to calculate the speed the bear shows and the ↓ download ↑ upload tooltip.
  • The taskbar theme. Whether it's in light or dark mode, to pick the bear's colors.

NetBear does not read the content of your traffic, the sites you visit, your IP addresses, network names, files or account data. The values it reads are only used in memory to draw the icon and are discarded at the next measurement. Nothing is written to disk.

What it stores on your device

One thing, and only if you turn on Iniciar con Windows (start with Windows) in the app menu or the installer: a value named NetBear in HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run with the program's path. It's removed when you turn the option off or uninstall NetBear.

Internet connections

NetBear does not connect to any server. It has no telemetry, analytics, ads, crash reporting or automatic updates. Nothing it does depends on an external service.

The GitHub option in the menu opens the project page in your browser. From there, the GitHub privacy statement applies.

Data shared with third parties

None. NetBear does not sell, rent or share information with anyone, because it doesn't collect any.

Microsoft Store

If you install NetBear from the Microsoft Store, Microsoft processes download and installation data under the Microsoft Privacy Statement. The developer only receives aggregated Store reports, such as download counts, that don't identify anyone.

This website

This site is hosted on GitHub Pages. It uses no cookies, analytics, or third-party fonts or scripts. GitHub may log technical visit data, such as IP addresses, to operate and secure the service, under its own privacy statement.

Children

NetBear does not collect data from anyone, including children under 13.

Your rights

Since NetBear stores no personal data, there is no information about you to access, correct or delete. If you still have a request or a question, write to us and we'll reply.

Changes to this policy

If NetBear ever changes how it handles information, this page will be updated before that version is released and the date above will change. The full history is in the project repository.
