Support

NetBear is maintained by one person. I reply as soon as I can

Report a problem Open an issue on GitHub. It's the fastest way and helps others with the same problem github.com/owenunda/NetBear/issues Send an email For private questions or if you don't have a GitHub account owenunda@gmail.com

What to include

  • Your Windows version. You'll find it in Settings › System › About.
  • Your NetBear version and whether you used the installer, the portable version or the Microsoft Store.
  • What the bear does and what you expected. A screenshot helps a lot.

Frequently asked questions

I can't see the bear on the taskbar
Windows may hide new icons. Click the ^ arrow next to the clock and drag the bear onto the taskbar, or turn it on in Settings › Personalization › Taskbar › Other system tray icons.

I'm connected to Wi-Fi but the bear doesn't hibernate
The bear hibernates when no adapter has a default gateway. If your Wi-Fi is connected but the router has no internet, the bear stands still instead of hibernating.

I use a VPN, WSL or Hyper-V
Virtual adapters without a default gateway don't count, so they don't double the speed or keep the bear awake without internet. USB tethering from your phone does count as a connection.

Windows says "Windows protected your PC"
This happens with the GitHub download because the executable isn't signed yet. Choose More info and then Run anyway. The Microsoft Store version doesn't show this warning.

I don't want it to start with Windows
Right-click the bear and uncheck Iniciar con Windows (start with Windows).

How do I uninstall it
Go to Settings › Apps › Installed apps, find NetBear and choose Uninstall. If you use the portable version, close the app from its menu and delete the file.

Does NetBear send my data anywhere?
No. The app doesn't connect to any server. The details are in the privacy policy.
